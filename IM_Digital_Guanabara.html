Esse framework é o que separa análise de opinião — toda afirmação tem nível de evidência explícito.
P1 — Bullet charts de urgência (bloqueia decisão hoje)

O GA4 é permissão de leitura — não é projeto de TI. A política de preço OTA é pergunta para o time comercial — não é dado técnico.
P2 — CAC por canal e Elasticidade da taxa de conveniência
CAC: (Investimento mídia ÷ tickets próprio) vs (comissão paga ÷ tickets Terceiros). Define o break-even real entre os canais — não é só margem, é custo de aquisição. Elasticidade: o canal próprio não cobra taxa de conveniência, mas isso não significa que o passageiro escolhe o canal próprio automaticamente. Precisa de análise de comportamento via GA4 + CRM para entender o que realmente determina a escolha de canal.
P3 — Monitoramento contínuo: Viva Fidelidade, Precificação, Customer 360
LTV Viva Fidelidade: programa com +1M de usuários define onde está o valor real de recorrência. Performance por canal: se pontos acumulados no próprio reduzem share do Terceiros, o programa é o principal instrumento de migração de canal sem desconto. Precificação dinâmica: diesel é o 2º maior custo operacional — alertas de distorção tarifária são essenciais. Customer 360: CPF como chave de correlação entre App, site, WhatsApp e guichê. Sem CPF os dados ficam em silos mesmo com ferramentas caras.

Rafael: "Como prioriza investimentos com orçamento limitado?"
Semanas 1–2 são tempo, não budget. Power BI provavelmente já existe no grupo. O maior desperdício não é budget — é tomar decisões sem dado. O Case 02 custou R$293k/viação/ano em receita não capturada. Qualquer licença custa menos.
Henrique: "E se o BI de TI não conseguir atender?"
Construo em paralelo com o que existe. O Case 02 foi feito com a planilha que me mandaram. Para o BI TI, pedido pequeno + impacto justificado. Excel imperfeito em 2 semanas é melhor que esperar o sistema perfeito.
Henrique: "Prazo realista para o report do Case 01?"
